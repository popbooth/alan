# 物化生可报专业清单（2026年更新）

> 更新: 2026-06-26 | 覆盖率: 约96.36%

## 2026年专业选择趋势变化

### 上升行业（强烈推荐）
1. **微电子/集成电路** — 2026年薪资榜第1，连续5年绿牌，芯片国产化核心
2. **自动化** — 2026年首次登绿牌榜，工科万能专业（电气+编程+控制）
3. **电气工程及其自动化** — 连续5年绿牌，国家电网+新能源双方向
4. **新能源科学与工程** — 3年上榜绿牌，双碳政策长期利好
5. **车辆工程** — 新能源车带动回暖，连续2年绿牌
6. **材料科学与工程** — 2026年首次进入高薪TOP10

### 降温行业（需理性评估）
1. **计算机科学与技术** — 跌出高薪TOP10，供需趋于平衡
2. **软件工程** — 退出绿牌名单，AI替代基础编程岗位
3. **金融学/管理学** — 管理类大量撤销布点，就业竞争激烈

### 稳定方向
1. **AI/人工智能** — 算法工程师需求增长110%，但门槛极高（一般要求硕博）
2. **临床医学/口腔医学** — 稳定但培养周期长（5+3+X）
3. **电子信息类** — 受益于半导体产业，持续景气
