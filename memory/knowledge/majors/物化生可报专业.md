# 物化生组合可报专业清单

> 更新: 2026-05-29 | 覆盖率: 96%~98%

## 可报专业大类

| 大类 | 具体专业 | 建议关注度 |
|------|---------|-----------|
| **医学类**（最全） | 临床医学、口腔医学、中医学、药学、麻醉学、医学影像、护理学 | ⭐⭐⭐⭐⭐ |
| **计算机/电子信息** | 计算机科学、软件工程、人工智能、数据科学、通信工程、集成电路 | ⭐⭐⭐⭐⭐ |
| **机械/电气** | 机械工程、电气工程、自动化、机器人工程、智能制造 | ⭐⭐⭐⭐ |
| **理科基础** | 数学、物理、化学、统计学、生物科学、环境科学 | ⭐⭐⭐⭐ |
| **部分经管** | 经济学、金融学、会计学、管理科学与工程 | ⭐⭐⭐ |
| **法学/师范**（部分） | 部分不限选科的专业 | ⭐⭐⭐ |

## 不能报考的专业

- 历史学类、考古学
- 部分汉语言文学（纯文科方向）
- 部分哲学、艺术史

## 推荐方向（结合产业趋势）

1. **AI/计算机** → 目前最热门，需供比高，薪资起点高
2. **临床医学** → 稳定高薪，但学业周期长（5+3+X）
3. **电子信息/集成电路** → 国家紧缺，人才缺口超100万
4. **生物医药** → 创新药研发方向，与生物学科匹配
5. **新能源/电气** → 国家重点产业，江苏优势明显
