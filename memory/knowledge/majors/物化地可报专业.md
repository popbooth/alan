# 物化地组合可报专业完整清单（2026年更新）

> 更新: 2026-06-26 | 覆盖率: 约95.4%（可报约705个本科专业）
> 数据来源: 教育部选科指引、各高校2026年招生简章、江苏省教育考试院

## 物化地 vs 物化生 核心差异

| 对比维度 | 物化生 | 物化地 |
|---------|--------|--------|
| 专业覆盖率 | 约96.36% | **约95.4%** |
| 临床医学 | 全部可报 | **约85%院校可报**（159所仅要求物化，28所要求物化生） |
| 口腔医学 | 全部可报 | 大部分可报（少数要求生物） |
| 地理/遥感/GIS | 部分可报 | **全部可报，且是优势方向** |
| 地质/测绘/气象 | 部分可报 | **全部可报，天然适配** |
| 生物科学/生物工程 | 全部可报 | 部分不可报 |
| 赋分竞争 | 生物考生多，中等 | 地理考生多，中等 |
| 适用场景 | 目标学医或生物方向 | 对医无感，地理有优势 |

## 六、选科决策参考

**选物化地的理由：**
- 地理成绩明显优于生物
- 对医学无强烈兴趣（或仅考虑可报的临床院校）
- 对地理/GIS/遥感/地质/气象/城市规划有兴趣
- 想利用地理赋分优势（地理中等难度，竞争适中）

**选物化生的理由：**
- 生物成绩明显优于地理
- 目标明确要学医/生物方向
- 想保留最完整的专业选择权
