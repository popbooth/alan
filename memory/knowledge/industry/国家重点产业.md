# 国家战略新兴产业方向

> 更新: 2026-05-29 | 来源: "十五五"规划纲要、人社部、工信部

## 六大科技赛道

1. **人工智能** — AI岗位需供比 3.5:1，应届硕士起薪30-50万
2. **半导体/集成电路** — 人才缺口超100万，后端工程师需供比 6.43
3. **人形机器人** — 新风口，2026年Q1服务机器人产量增6倍
4. **低空经济** — 政策密集出台，无人机/飞行汽车方向
5. **新能源与储能** — 智能驾驶需供比 16:1（最紧缺），固态电池、氢储能
6. **生物医药与长寿科技** — 创新药、AI辅助诊断、合成生物学

## 人才缺口数据

| 领域 | 需供比 | 应届硕士起薪 |
|------|--------|------------|
| AI算法 | 3.5:1 | 30-50万 |
| 芯片设计 | 6.4:1 | 40-60万 |
| 智能驾驶 | 16:1 | 30-50万 |
| 新能源技术 | 5.1:1 | 25-40万 |
| 生物医药研发 | 紧缺 | 20-35万 |

## 对 Alan 的参考价值

- 物化生组合完美覆盖上述所有领域
- AI/半导体 适合数学+物理强的学生
- 生物医药 适合化学+生物强的学生
- 新能源 适合物理+化学强的学生
