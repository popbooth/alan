# 国家重点产业方向（2026年更新）

> 更新: 2026-06-26 | 来源: "十五五"就业优先规划、教育部2026专业目录、麦可思蓝皮书

## 国家战略产业全景

### 十五五核心赛道
1. **人工智能+** — AI渗透率预计30%-50%，算法工程师需求增长110%，人机协同新职业涌现
2. **半导体/集成电路** — 微电子科学与工程登顶2026年薪资榜，连续5年绿牌
3. **新能源与储能** — 新能源科学工程3年上榜绿牌，智能驾驶需供比16:1
4. **低空经济** — 2026年新增低空经济与管理、低空安全管理专业
5. **生物医药与长寿科技** — 创新药、AI辅助诊断、生物制造（新增专业）
6. **具身智能与未来机器人** — 2026年新增具身智能专业，交叉学科门类首批

### 新增专业方向（2026年教育部目录）
- **交叉学科门类首次设立**：具身智能、脑机科学与技术、智能计算
- **数字经济**：数字金融、数字贸易、低空经济与管理、数据资源与数据智能
- **能源交通**：能源科学与工程、交通能源融合工程、半导体工艺与装备
- **深地深海**：深地科学与工程、海洋智能与无人技术
- **生物农业**：生物制造、农业机器人、智慧渔业

### 撤销/停招集中的专业（需规避）
- **管理类大量撤销**：信息管理与信息系统（5年撤160个）、公共事业管理、市场营销
- **传统计算机降温**：计算机科学与技术、软件工程跌出高薪TOP10
- **文科艺术类持续承压**：绘画、音乐表演连续5年红牌
