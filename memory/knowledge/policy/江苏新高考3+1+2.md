# 江苏新高考 3+1+2 政策（2026年更新）

> 来源: 江苏省教育考试院 (jseea.cn) | 更新: 2026-06-26

## 考试模式

| 层级 | 说明 | 科目 | 分值 |
|------|------|------|------|
| 3 | 全国统考 | 语文/数学/外语(含听力30分) | 各150分，原始分 |
| 1 | 首选(2选1) | 物理 或 历史 | 100分，原始分 |
| 2 | 再选(4选2) | 政治/地理/化学/生物 | 各100分，**等级赋分** |

总分: **750分**

## 选科与专业报考

选科必须符合高校专业组要求，分四种：
- 选1科: 必须选考该科
- 选2科: 必须同时选考2科
- 选3科: 必须同时选考3科
- 不提要求: 无限制

## 物理+化学组合覆盖率

| 选科组合 | 专业覆盖率 | 说明 |
|---------|-----------|------|
| 物理+化学+生物 | 约96.36% | 最全，覆盖临床医学 |
| 物理+化学+地理 | 约95%+ | 覆盖率略低于物化生，主要差异：不能报临床医学 |
| 物理+化学+政治 | 约90.43% | 利于考研/考公 |
| 仅选物理（不选化学） | 约10% | 选择范围极窄 |

## 物化地 vs 物化生 关键差异

| 对比维度 | 物化生 | 物化地 |
|---------|--------|--------|
| 专业覆盖率 | 约96.36% | 约95%+ |
| 临床医学 | 可报 | **不可报**（绝大部分要求生物） |
| 口腔医学 | 可报 | 大部分不可报 |
| 地理相关专业 | 可报（少） | 可报（气象、地质、遥感等） |
| 生物相关专业 | 可报 | 部分不可报 |
| 赋分竞争 | 生物考生多，中等难度 | 地理考生多，中等难度 |
| 适用场景 | 目标明确要学医 | 对医无感，地理更有优势 |

## 注意事项
- 合格性考试不合格不能参加对应选择性考试
- 招生计划按"历史等科目类"和"物理等科目类"分别编制
- 志愿填报以"院校专业组"为基本单位
