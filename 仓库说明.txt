每次改完代码后上传

cd "d:/AI/Alan's Future Plan"
git add -A
git commit -m "改了什么东西"
git push
换电脑了，第一次拉下来

cd d:/AI
git clone https://github.com/popbooth/alan.git
后面每次在这台电脑上改完，同样 git add -A && git commit -m "xxx" && git push

另一台电脑上同步最新代码

cd "d:/AI/Alan's Future Plan"
git pull
就这三板斧：

场景	命令
改完上传	git add -A && git commit -m "说明" && git push
新电脑第一次	git clone https://github.com/popbooth/alan.git
同步别人改的	git pull
GitHub Actions 会自动部署，PAD 刷新就是新版。
